Eight small tools for ChatGPT and Codex, running here on real data.

Each key loads that plugin’s own Python file and runs it in your browser. Where a tool needs something a browser cannot give it, the printout says so.

No account, no telemetry. The tools run in your execution environment, or here in your browser.

The tool reads the actual file.

Results come from parsing the input you give it. Nothing is guessed from a filename or an extension.

You can check the work.

Hashes, source-row ranges, budgets and undo receipts come back alongside the answer.

Install only what you need.

Each plugin is a separate package. A tool that needs FFmpeg or ezdxf says so before it runs.
