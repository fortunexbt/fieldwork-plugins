Where your data goes.

Fieldwork is a collection of open-source skills and scripts maintained by Fortune. The scripts run in the execution environment you give them. Fieldwork does not operate a processing server, user account system, or analytics service.

Files and results

Tools read the files or directories you select and write the reports, converted copies or receipts you request. Those files remain in that execution environment until you move or delete them. Installing a plugin does not automatically upload your files to the publisher. The host product, such as ChatGPT or Codex, processes the conversation and tool output under its own policies.

Network requests

ShipProof requests the URLs you ask it to verify. CI Spend Check can use your existing GitHub CLI connection to read workflow data from GitHub. Requests expose ordinary connection information to those destinations. Other workflow dependencies may require a download that the skill identifies before setup. Credentials stay with the host or the external CLI; they are not sent to a Fieldwork service.

This website

The catalog is hosted on GitHub Pages. GitHub may process connection information under its own privacy policy. The catalog adds no analytics, cookies, tracking pixels or account login. Copy buttons use your browser clipboard only when selected.

What you control

You choose the input files, execution environment and commands. Review generated reports before sharing them: they can contain filenames, paths, repository identifiers or data from your inputs. You can remove the installed plugins and delete their generated files at any time.

Support

Use the public issue tracker for support. Issues and attachments are public; share a synthetic reproduction instead of credentials, private recordings, customer drawings or raw logs containing personal information.
