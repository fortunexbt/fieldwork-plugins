Install in Codex

Run codex plugin marketplace add fortunexbt/fieldwork-plugins once. Then install the plugin you need, for example codex plugin add tablebeam@fieldwork. Start a new chat to load the installed skill. In the desktop app, browse the Fieldwork marketplace under Plugins.

Execution requirements

These packages contain skills and scripts. They require an execution-capable host with access to the selected input. Python 3.11 or newer is the base requirement. Fit to Upload additionally uses FFmpeg and FFprobe. Minecraft live capture requires the supported local macOS game setup. CAD conversion and GitHub inspection have their own documented dependencies.

A web or mobile chat does not automatically gain access to your computer's files, games or installed executables. A skill can explain or analyze evidence only where the required execution tools and input files are available. Check each plugin's instructions before using it on a new platform.

Try the included sample

Each plugin contains a small synthetic example or reproduction recipe. Run that first to check dependencies. The examples shown in the catalog come from these tools; they are not performance claims about your computer or your data.

Report a problem

Open an issue with the plugin version, operating system, command, observed result and a small synthetic input. Keep private data out of public reports. Open the issue tracker ↗

Publication status

Direct source and marketplace distribution are separate from approval in OpenAI's public plugin directory. The release ledger records the verified state of each package. A download link is not evidence of directory approval.
